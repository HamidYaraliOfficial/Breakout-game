# Breakout Deluxe

A modern and visually enhanced Breakout game built with **Python** and **PyQt6**.

---

# 🇬🇧 English

## Overview

Breakout Deluxe is a polished desktop implementation of the classic Breakout arcade game. It features modern graphics, particle effects, multiple themes, multilingual support, combo scoring, level progression, and responsive controls.

The project is designed as a clean and educational PyQt6 example while also delivering an enjoyable gaming experience.

---

## Features

### Gameplay
- Classic Breakout mechanics
- Multiple levels with increasing difficulty
- Progressive ball speed scaling
- Life system
- Combo score multiplier
- High score tracking
- Pause and resume functionality

### Visual Effects
- Smooth animations
- Particle explosion effects
- Ball trail effects
- Dynamic brick damage indicators
- Paddle glow effects
- Modern gradient-based rendering
- Dark and Light themes

### User Experience
- Mouse control support
- Keyboard control support
- Responsive interface
- Real-time statistics panel
- Multilingual interface

## 项目简介

Breakout Deluxe 是使用 Python 与 PyQt6 开发的现代化打砖块游戏。

项目在保留经典街机玩法的同时，加入了现代界面设计、粒子特效、多语言支持以及主题切换功能。

- 连击得分系统
- 最高分记录
- 暂停与继续功能

### 视觉效果
- 流畅动画
- 粒子爆炸效果
- 小球拖尾效果
- 砖块受损显示
- 挡板发光效果

- 深色与浅色主题

### 用户体验
